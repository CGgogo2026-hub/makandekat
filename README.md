# MakanDekat

Landing page statis untuk Milestone 10 Lab Startup Bisnis Digital.

## Isi
- `index.html`: landing page responsif, copywriting, CTA, FAQ, dan formulir minat.
- Formulir saat ini menampilkan status belum aktif karena alamat penerima lead belum dikonfigurasi.
- Kode GA4 belum diaktifkan karena Measurement ID belum diberikan.

## Publikasi dengan GitHub Pages
1. Buka tab **Settings** pada repository.
2. Pilih **Pages** di menu kiri.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
5. Tunggu proses publikasi. URL proyek akan berbentuk `https://cggogo2026-hub.github.io/makandekat/`.

## Konfigurasi sebelum pengumpulan final
- Formulir lead perlu alamat email admin yang disetujui atau endpoint form yang dimiliki tim.
- Analytics perlu Measurement ID GA4 yang sebenarnya.
- Setelah konfigurasi, uji satu pengiriman formulir dan periksa GA4 Realtime. Jangan menyatakan lead/analytics aktif sebelum pengujian berhasil.

## Catatan data
Tidak ada testimoni, jumlah pengguna, harga tempat makan, rating, atau jam buka yang dibuat-buat. Landing page menjelaskan produk sebagai layanan tahap pengembangan/validasi.
